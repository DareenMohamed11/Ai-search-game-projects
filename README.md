# AI Search and Game Projects

A collection of academic AI projects implemented in Python.

## Projects

### Connect4 AI Game
- Connect4 game with a Tkinter GUI.
- Implements Minimax, Alpha-Beta Pruning, and Expectiminimax.
- Uses heuristic evaluation and logs results for comparison.

### Sudoku CSP Solver
- Sudoku solver and GUI.
- Implements backtracking, MRV, LCV, forward checking, AC-3 constraint propagation, puzzle generation, and uniqueness checking.

### 8-Puzzle Search Algorithms
- Solves the 8-puzzle problem using BFS, DFS, Depth-Limited Search, Iterative Deepening Search, and A*.
- Includes Manhattan and Euclidean distance heuristics.
